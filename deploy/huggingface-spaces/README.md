# ARS-VG Analyzer

**AEM-REM Substitution and Vulnerability Graph Analyzer**

A forensic accounting research tool for detecting earnings manipulation through
graph-based analysis and explainable AI.

## Features

- Graph-based earnings manipulation detection (AEM/REM substitution)
- Beneish M-Score and Dechow F-Score benchmarking
- Historical fraud case retrieval (JarFraud dataset)
- Interactive vulnerability graph visualizations
- Cross-validated statistical validation
